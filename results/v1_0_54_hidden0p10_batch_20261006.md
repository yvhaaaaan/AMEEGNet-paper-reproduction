# v1.0.54 Dense(32) max-norm batch

The Dense(32) max-norm threshold `0.10` was selected from an A01-only,
source-session 80/20 validation screen without reading the target labels. The
follow-up batch then returned to the paper-style protocol: all 288 trials in
the source session were used for training, 1000 epochs were run, and the
target session was evaluated once at the final epoch.

## Nine-subject result

| subject | final target accuracy |
| --- | ---: |
| A01 | 83.33% |
| A02 | 45.49% |
| A03 | 93.75% |
| A04 | 68.40% |
| A05 | 43.06% |
| A06 | 59.38% |
| A07 | 81.94% |
| A08 | 84.03% |
| A09 | 80.90% |

Mean +/- sample SD: **71.14% +/- 18.13%** (n=9), which is -10.03
percentage points relative to the paper's 81.17% mean.

All nine records passed the batch audit: 1000 history entries, no target
evaluation during training, one final target evaluation, balanced 288-trial
test labels, matching source hashes and matching configuration fields.

## Decision

The A01 source-validation result was not representative of the nine-subject
target-session result. The threshold `0.10` is rejected for the formal batch;
the v1.0.52 candidate with Dense(32) threshold `0.25` remains the best
final-only nine-subject result at 78.67% +/- 9.82%.
