# Frozen source cuDNN precision results at v1.0.82

## Scope And Provenance

The [v1.0.81 registration](v1_0_81_frozen_tf32_preregistration.md) was
executed with corrected metadata comparison at clean commit
`dd729c2c527ebfa2df13f226b7275a0af07738c8`, tag `v1.0.82`.
P1 initially failed on PT tuple/TorchVersion versus JSON list/string
comparison; the fix canonicalizes metadata through JSON and has a
regression test. No training/model/data source or dependencies changed.
Repeated P1 passed before the full diagnosis.

Twelve final ELU checkpoints were examined: A01/A02/A04/A06, each with
seeds 1/7/2025. The first nine are v1.0.74 controls and the three A06
weights are v1.0.80 controls. Only their recorded 58 source-validation
trials were evaluated. No target Session was evaluated or predicted.

Each frozen model received two float32 CUDA forwards with only
`cudnn.allow_tf32` permission changed. Matrix TF32 remained disabled,
deterministic algorithms/cuDNN remained enabled, and benchmark remained
disabled. The permission was restored after inference; no parameter,
optimizer or BN update occurred. CE diagnostic loss is computed on CPU
after copying the CUDA logits, not timed as GPU training.

Different source seeds/partitions remain repeated within-subject
observations, not twelve independent subjects.

## Independent QA And Interpretation

P2 passed after reproducing the twelve-checkpoint CLI in 20.873 seconds.
Its temporary JSON matched the recorded output byte-for-byte, including
last-bit floating values. All source partitions/labels, data/code hashes,
PT/JSON metadata and final checkpoint fingerprints matched. Actual
backend flags and eval/inference mode were observed directly.
All 152 monitored files remained hash-identical: 111 tracked files,
36 reference artifacts, four source caches and the diagnostic output.
Temporary output was removed. Seven affected tests passed, and the
complete suite contains 39 passing tests.

Local full output: `results/frozen_tf32_v1_0_81/summary.json`.
The directory retains the registration version; the output records the
actual diagnostic commit corresponding to tag `v1.0.82`.
Reproduce with `audit_frozen_tf32.py --checkpoint` followed by all twelve
registered PT paths, and `--out` pointing to a fresh JSON path.

These observations establish negligible logit changes and identical
source predictions for these frozen forwards. They do not establish
actual TF32 kernel usage, rule out training/backward numerical effects,
or explain the nine-subject gap to the paper. No new model was trained
or tested, and no permission mode is selected for individual subjects.
The failed v1.0.80 no-ELU expansion gate remains failed. Any later
training diagnosis requires a separate fixed source-only protocol;
this inference-only result does not authorize a target batch.
